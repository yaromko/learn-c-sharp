
# [Learn C\#](https://github.com/yaromko/learn-csharp "Learn C#")

A collection of beginner-friendly C# console programs that focus on practicing loops and conditional statements (`if`). Each problem demonstrates how to use loops and conditionals to solve common programming tasks, especially those involving arrays and basic math.

## Projects Overview

| Project | Description |
|---------|-------------|
| [HelloWorldCliApp](/HelloWorldCliApp/ "Hello World CLI App") | A simple console application that prints "Hello, World!" to the console. |
| [LoopExamples](/LoopExamplesCliApp/ "Loop Examples CLI App") | Some simple console programs that demonstrate the use of loops and conditional statements in C#. |
| [RockPaperScissors](/RockPaperScissorsCliApp/ "Rock Paper Scissors CLI App") | A console application that allows the user to play the classic game of Rock, Paper, Scissors against the computer. |
