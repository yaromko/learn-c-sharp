
# LoopExamples

This project contains a collection of beginner-friendly C# console programs that focus on practicing loops and conditional statements (`if`). Each problem demonstrates how to use loops and conditionals to solve common programming tasks, especially those involving arrays and basic math.

## Problems Included

### 1. Count Odd Numbers

Reads a list of integers (terminated by -1) and computes the frequency of odd numbers entered.

### 2. Find Indices of 'e' in a String

Prints the index of each occurrence of the letter 'e' in the string:  
`"Welcome to programming exercises"`

### 3. Student Grade Tracker (Menu-Driven)

A console menu program that allows you to:

- - Enter a student’s name
- Add grades (0–100)
- Calculate and display the average grade
- Reset the student and grades
- Exit the application

### 4. Compare Numbers to the First Element

Reads a list of 12 numbers and prints only those values that are greater than the first number entered.

### 5. Frequency of Dice Rolls

Simulates rolling a six-sided dice 500 times, stores the results in an array, and computes the frequency of each number (1 through 6).

## Learning Focus

- Using `for`, `while`, and `foreach` loops
- Applying `if` statements for decision making
- Working with arrays and collections
- Basic input/output in C# console applications

## How to Run

1. Open the project in Visual Studio 2022.
2. Replace the contents of `Program.cs` with the code for the problem you want to run.
3. Build and run the project.

---

This project is ideal for anyone looking to strengthen their understanding of loops and conditionals in C#.
